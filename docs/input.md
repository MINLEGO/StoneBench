# Vanilla input contract (issue #8)

`declare_input` identifies an existing inactive wall device by registry `device`, `position`, outward cardinal `orientation`, and adjacent `input_block`. The controller checks the catalog, actual wall attachment/support, inactive signal and exterior lateral plane of the live observed non-air construction envelope. Up/down, unsupported devices, missing support, nonadjacency and interior input planes fail. The observation coverage limits remain applicable; this is not universal geometry certification.

`prepare_input(mode=direct|repeater)` uses frozen chunk preparation and consumes zero world/simulation ticks. Direct retains the declared device. Repeater replaces that exterior device coordinate with a real delay-1 vanilla repeater whose output points toward the construction (its facing property is the outward direction), installs its floor, an exterior support one block farther out and the same wall device two blocks farther out. The source and received input must initially be inactive, and all three extra coordinates must be vacant. These are adapter preconditions, not general construction conformity rules. Those blocks belong to the adapter. The construction before/after records retain exact typed NBT, inventories, queues, absolute deadlines/priorities/order; the preparation returns `construction_preserved` and an immutable differences artifact. A mismatch is an infrastructure error with actual operation observations, never a successful preparation. Rebuild or restore the direct state before changing back from repeater mode. Modifying the interface or any adapter coordinate invalidates the declaration.

`act_input(ticks=1..6000, trace=true|false)` serializes with every other operation, requires ready chunks and no players, invokes `LeverBlock.togglePower` or `ButtonBlock.powerOn` at `ServerWorld.tickTime` HEAD before time increments, and executes exactly the requested vanilla unit ticks. The lever naturally toggles; buttons naturally release on vanilla callbacks. No powered state, tick queue, deadline or pulse duration is set by the controller. An already-powered button must reach its natural release before another press; the tool rejects premature re-presses. Call `act_input` again for the lever's closing interaction; let the chosen button release with the requested ticks or later `advance` calls.

Events `input_interaction`, `input_device_change`, and `input_signal_change` carry the same operation/tick/simulation indexes, absolute world/time-of-day clocks and phases as all observation events. The latter reports the actual received power at `input_block`. Source and input edges distinguish adapter latency from circuit latency. General block write and piston events retain circuit changes. No player network path is exercised.

Snapshots preserve complete raw `state.blocks` and add independent immutable `adapter_blocks` and `construction_blocks` references containing the exact records from the same sample. Queues remain complete in raw state. `Inputs.adapter(BlockPos)` identifies ownership; `Inputs.expectedExternalEvent(BlockPos)` identifies candidate natural button/repeater callback positions for downstream rest diagnostics; consumers must match the scheduled type and actual state rather than ignoring every external event. `describe_task.input` and `Inputs.declared()` return null or a fresh JSON description: `device`, original `position`, actual `driver`, `input_block`, `support` (construction), outward `orientation`, `face=wall`, `validation=validated_lateral_exterior`, `mode`, and `adapter_positions`. Consumers must still check actual state/support and observation coverage before certification.

The test matrix intentionally compares selected behavioral outputs at stable endpoints. It retains absolute traces unchanged and does not use `compare_traces` to claim equality for executions beginning at different absolute clocks. At each tested endpoint, all 220 fixture construction coordinates (air included) retain typed chest NBT/inventory and the whole piston mechanism. Delay calculations subtract recorded simulation indexes; fields omitted from endpoint comparisons are the explicitly external adapter, global clocks, observed positions outside the declared test fixture and queues already asserted empty. This establishes these fixtures, not a full regular DOOR or fidelity of arbitrary JVM memory.
