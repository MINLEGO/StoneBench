# Évaluer dans un serveur Minecraft dédié

StoneBench exécute les constructions dans un serveur Minecraft Java dédié, en version 1.21.11, plutôt que dans une simulation redstone indépendante. Ce choix conserve le jeu comme référence pour les interactions entre composants et évite de devoir réimplémenter ces interactions pour rendre un verdict ; il implique en échange de contrôler une version et un environnement de serveur précis. Le mécanisme de pilotage reste à définir.
