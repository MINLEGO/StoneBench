# Source-defined measurements (issue #13)

`verify_checkpoint` keeps the independent-copy alpha protocol and adds `measurements` to its report. `dynamic_volume`, `opening_time` and `closing_time` are separate objects with `status`, nullable exact `value`, units, gaps and source locators. `transitions[]` keeps every executed repeater cycle and the direct diagnostic cycle, movement provenance, original interaction, signal arrival, movement completion and rest recognition. The direct mode never replaces repeater timing. No fused score or community-record claim is produced. A nonconformant or interrupted verification keeps diagnostic measurements and `record_eligibility=not_verified`.

The source is the locally frozen native Door Rules revision `AHj4eMT_keZ9k_mo9La-s7C1bFHDqp8qAcERIYP8JSNCf922quSNhQQ0ICk0WEgJCGqRKxiqzo8qUe4DNy7-4Q`, cache SHA-256 `e4a01f6d47956291bb9952392e3cf8216f2dc3c4537a81aaea0ccaf73e44eb68`. Locators are native Google Docs character indexes, not generated PDF pages. The frame/physical enclosure distinction retains [the multi-source geometry table](rules/regular-door.md), including Dummies cache SHA-256 `0c022decbc7532c0d2383e21bd6fb53d8554e94809be70dffc035e78a486aad9`. Full native texts remain local; the operational table below paraphrases them.

The source explicitly says **start +2**, not completion +2. Adding two ticks to an already completed movement would double-count the prescribed offset. The implementation and fixture expectations use the native source, rather than that ambiguous earlier handoff wording. Game ticks are the metric; operation wall seconds and execution backend stay separate.

`Measurement` observes outline extents of actual states, effective intra-tick block writes, and every moving piston before/after progress and forced completion. Moving piston placeholder cells do not replace actual mobile extents. Vanilla `getHeadBlockState` supplies the head's real short/long state; facing/progress offset positions it in world coordinates. Consecutive positions cover each linear translation; sources, destinations, block identities, callback order and power edges retain provenance. Source samples may disappear from a tick's final state and remain in the intra-tick artifact. Every changed block write requires its extent event, and every mobile position requires a matching movement-start sample.

Input connection is assessed only in the covered bounded protocol: initially empty queues, one input origin, complete ordered vanilla read/write/event traces and validated checkpoint memory. Reads used by measurement/snapshot serialization are suppressed by the existing observation guard and cannot manufacture connectivity. The complete event cone bounds observed input connection; it does not prove the counterfactual necessity required by wiring. Reads, notifications and even active or redundant movement cannot establish that removing each block prevents the door from functioning. Only the declared input block has certain membership here. Every other observed material/component/mobile extent remains conditional unless a source-defined exclusion applies; untouched comparison controls remain outside the covered observed cone. Missing origin, queues, observations or memory makes the exact metric indeterminate.

Hallway contents are counted in a proven opened endpoint; unproved intermediate/nonopen hallway membership remains conditional under rule 24616. Every observed block with unresolved circuit necessity is conditional, including passive enclosure/supports and active redundant components. The report retains minimum/maximum envelopes. An exact rounded dimension is available only when both agree after ceiling; otherwise `value=null` and the gap is explicit. The cumulative summary repeats this check across all repeater states/cycles. Piston heads/components are retained wiring even when their collision plate supplies physical enclosure. Complete raw snapshots, NBT, inventories, runtime fields, ordered queues and clocks remain intact; no field is discarded from construction comparison to obtain equality.

Opening/closing timing keeps interaction and first signal arrival with absolute clock, simulation index, phase and event order. `adaptation_ticks` measures that interval; `door_response_ticks` starts at the signal. The report also keeps pertinent movement start/end, last circuit movement end, last observed construction change and rest recognition. Opening uses movements intersecting the immutable hallway rays; closing uses provenance from the same mechanism's closed door frame. A failed requested pattern, missing movement/power event, unclassified early finish or incomplete rest leaves exact timing indeterminate. A resting non-door does not become a timed door.

The existing asynchronous request/status/cancel flow, working-world lease, native sprint default, per-transition 36000 game ticks and derived 432000 bound remain unchanged. No independent global quota is introduced. Measurement/archive runs inside the existing finite phase watchdog. Durable cancellation and the final `Workers.lock` publication veto remain in place; both supervisor and final controller publication revoke measurement interpretation to diagnostics if conformity is revoked.

`tests/measurements.py` runs the delivered MCP/checkpoint verifier against the vanilla 2x2 quartz fixture from #12, with one added delay-4 repeater/piston branch outside hallway rays. Door completion stays 6gt in repeater mode (2gt adaptation +4gt response), while the later circuit movement extends rest. The original observed cone spans x1018..1032, y79..83 and z1022..1025 inclusive: 15*5*4 =300. The review regression adds a redundant stone beside the late piston at x1033/y81/z1025. It is notified by vanilla and expands the observed high bound to 16*5*4 =320 while the door still takes 6gt. Neither notification nor the unchanged speed proves necessary wiring membership: exact volume is indeterminate, value null, with lower/input and upper/observed envelopes retained. Isolated comparator-control chest/stone do not enlarge wiring. Actual enclosure/door/adapter role diagnostics and unchanged source-world snapshots are asserted.

A second real MCP fixture uses a vanilla observer 2gt pulse and a sticky piston, away from the task hallway. Initial/final connected bounds give 4*2*1 =8. The moving head reaches a fifth x cell, so the cumulative observed high bound is 5*2*1 =10; no stationary extended endpoint is used. Its exact wiring volume is also indeterminate because observation alone does not prove necessity. The source-defined 2gt extension and standard retraction are recorded. This deliberately non-door fixture retains timing-pattern failure as a diagnostic. Negative controls remove a real movement-start trace, veto trace completeness and remove memory coverage; exact volume becomes indeterminate. Pure tests cover axis-wise union, ceiling, cross-cycle union, all source timing offsets (including 0/1/2gt and instant), and missing pulse rejection.

Limits: native zero/one-tick pulse and instantaneous retraction montages are not asserted as runtime-proven by the 2gt observer fixture. Their source arithmetic is tested, and incomplete/unclassified events cannot be promoted to an exact metric. Non-quartz door substitution, unknown runtime memory, entities and universal circuit influence remain governed by the earlier mandatory gaps. Community-record reliability/isolation/seamless eligibility remains not verified.
